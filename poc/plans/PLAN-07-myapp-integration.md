# PLAN-07 — myapp: Wiring Everything Together

## Goal

Configure `apps/myapp` to use the `@poc/connect-angular` library and render a full working workflow builder demo with sample custom triggers.

## Context

- App path: `poc/apps/myapp/src/`
- App bootstrap: `poc/apps/myapp/src/main.ts` → `bootstrapApplication(AppComponent, appConfig)`
- App config: `poc/apps/myapp/src/app/app.config.ts`
- Root component: `poc/apps/myapp/src/app/app.ts` (or `app.component.ts` — check actual filename)
- The API server runs on `http://localhost:3333` (PLAN-01)
- The Angular dev server runs on `http://localhost:4200` (default NX `nx serve myapp`)
- Path alias `@poc/connect-angular` resolves to `poc/libs/connect-angular/src/index.ts`

## Prerequisites

PLAN-01 through PLAN-06 must be completed.

## Step 1 — Add environment files

Create `poc/apps/myapp/src/environments/environment.ts`:

```typescript
export const environment = {
  production: false,
  apiUrl: 'http://localhost:3333',
};
```

Create `poc/apps/myapp/src/environments/environment.prod.ts`:

```typescript
export const environment = {
  production: true,
  apiUrl: '/api', // reverse-proxy in production
};
```

Register environment file replacements in `poc/apps/myapp/project.json` under the `build` target's `configurations.production`:

```json
"fileReplacements": [
  {
    "replace": "apps/myapp/src/environments/environment.ts",
    "with": "apps/myapp/src/environments/environment.prod.ts"
  }
]
```

## Step 5 — Run both servers

```bash
# Terminal 1 — API
npx nx serve api

# Terminal 2 — Angular app
npx nx serve myapp
```

Open `http://localhost:4200`. You should see:
1. Sidebar with "Workflow Builder" heading and "New Workflow" button
2. Click "New Workflow" — a workflow appears in the sidebar and the builder canvas opens
3. The first step shows "Choose a trigger" 
4. Click it → expand → see your 3 custom triggers ("Order Created", "User Signed Up", "Payment Failed") and a "Browse Triggers" button
5. Select a custom trigger → step collapses with its name
6. Click "+ Add Step" → new unconfigured action step appears
7. Expand it → select an app (e.g. Slack) → select an action → ComponentForm renders

## Troubleshooting

**`PIPEDREAM_CONFIG` not provided error**: Check `app.config.ts` — `provideConnectAngular()` must be in `providers`.

**CORS error on token request**: Check that the API is running and `ALLOWED_ORIGIN=http://localhost:4200` is set in `poc/apps/api/.env`.

**SDK import errors**: If `@pipedream/sdk/browser` doesn't resolve, check the SDK package exports and adjust the import in `PipedreamClientService`.

**Empty app list**: Verify your Pipedream credentials in `.env` and that the token endpoint returns a valid token (test with `curl` as shown in PLAN-01).
